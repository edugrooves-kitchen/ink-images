# Ink & Inference portrait stills

`<tokenId>.png` is the still image marketplaces show for each portrait (InkRenderer `previewBase`). Drawn by the original art script exactly as the token page draws it, scaled to 600 px. `index.json` records what each image was drawn from (`agent`, or a swarm portrait's on-chain seed). The live art is always the token's own on-chain page (`animation_url`).
